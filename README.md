# LCM Analytics

Interactive review site for the LCM (Lifecycle Marketing) measurement framework — six proposed dashboards rendered with **synthetic data** so reviewers can see, interrogate, and sign off on every metric before anything is built in Tableau.

## What this is

- **Six dashboards** matching the measurement framework: Overall Executive View, Newly Enrolled, Stars, Consistent, Engagement Exposures, Needs Attention / Dormant. Naming follows the client documents verbatim.
- **Every metric is inspectable.** Right-click any metric (or click its ⓘ icon) to open the methodology panel: a plain-language explanation, the equation worked through with the live on-screen numbers, the formal definition, and the data source.
- **Feedback built in.** Reviewers vote Approve / Needs change / Question and comment per metric, plus dashboard-level composition feedback (does this view merit its own dashboard?). Feedback exports as a markdown sign-off matrix, cataloged in [`feedback/`](feedback/).

## What this is not

- Not connected to any real data system. All numbers are generated by a seeded synthetic engine at plausible scale. **No client data exists in this repository.**
- Not the production BI build — it is the approval vehicle for what that build should contain.

## Development

```bash
npm install
npm run dev      # local dev server
npm run build    # static build to dist/
```

Deploys to GitHub Pages automatically on push to `main` via `.github/workflows/deploy.yml`.

## Structure

| Path | Purpose |
|---|---|
| `src/data/registry.js` | Metric registry — single source of truth (names, definitions, equations, sources) |
| `src/data/synthetic.js` | Seeded synthetic data engine |
| `src/dashboards/` | One component per dashboard |
| `src/components/` | Charts, scorecards, methodology panel, feedback UI |
| `feedback/` | Catalog of exported reviewer feedback |
